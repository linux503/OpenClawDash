# OpenClaw 产品说明

## 一、产品概述

**OpenClaw** 是一个 AI 助手平台，支持多模型接入、工作空间管理、技能扩展与多种接入通道。通过统一的配置与 API，将 DeepSeek、OpenAI、Google 等主流模型接入到本地工作流中，并配合 **API 调用监控控制台** 实现用量与成本的可视化管理。

### 核心定位

- **多模型统一接入**：一份配置，多模型切换
- **本地优先**：数据与运行环境均可在本地掌控
- **可扩展**：技能系统支持按需安装与使用

---

## 二、主要功能

### 2.1 多模型接入

- 支持 DeepSeek、OpenAI（含兼容接口）、Google 等主流模型
- 统一配置、统一调用接口，便于切换与对比
- 支持 API 密钥与凭证的集中管理

### 2.2 技能系统

- 预置多种技能（如 GitHub、天气、笔记等）
- 可按需安装、启用技能
- 技能具备「可用 / 不可用」状态，便于排查依赖

### 2.3 工作空间

- 以项目为单位管理对话与工作目录
- 支持多项目并行使用

### 2.4 接入通道

- 支持 Telegram 等消息通道
- 支持 CLI 与本地集成

---

## 三、API 调用监控控制台

API 调用监控控制台是 OpenClaw 配套的 Web 控制台，用于**一站式监控 API 用量、成本与系统健康**。

### 3.1 功能模块

| 模块 | 说明 |
|------|------|
| **仪表盘** | 总费用、调用量、主模型、对话字数、缓存命中率等核心指标，支持「全部 / 近7天 / 今日」时间筛选 |
| **技能** | 查看已安装技能列表及可用状态，便于排查与优化 |
| **当前正在处理** | 实时展示运行中的任务，支持会话终止 |
| **最近调用** | API 调用记录，支持按 Provider、错误筛选及 CSV 导出 |
| **日志** | 查看系统与网关日志，支持多文件切换与实时刷新 |
| **系统信息** | 内存、硬盘、CPU、运行环境等系统健康指标 |

### 3.2 核心价值

- **成本可见**：按时间范围查看费用趋势，识别高消耗模型或时段
- **用量清晰**：Token、调用次数、错误率一目了然
- **问题定位**：通过日志、错误统计和系统信息快速排查异常
- **自动化**：数据每 30 秒自动刷新，无需手动操作

### 3.3 访问方式

- 本地访问地址：`http://127.0.0.1:18790`
- 支持 Mac / Windows，通过 Node.js 运行

## 四、适用场景

- **个人 / 团队 AI 开发**：统一管理多模型调用，控制 API 成本
- **项目成本分析**：按项目、按时间查看费用与用量分布
- **调试与排错**：通过日志和调用记录快速定位问题
- **技能管理与优化**：了解技能状态，合理规划依赖与安装

---

## 五、技术特性

- **数据本地化**：会话日志、用量数据均存储在本地状态目录
- **无外部依赖**：控制台为纯 Node.js 实现，无需数据库
- **轻量部署**：通过 npm 或 Homebrew 安装，数分钟即可完成初始化
- **跨平台**：支持 macOS、Linux、Windows

---

## 六、快速上手

1. 安装：`npm install -g openclaw` 或 `brew install openclaw`
2. 初始化：`openclaw onboard`
3. 启动控制台：`cd ~/.openclaw && ./scripts/service.sh start`
4. 访问：<http://127.0.0.1:18790>
